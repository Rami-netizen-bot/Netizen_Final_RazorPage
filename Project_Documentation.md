# NETIZEN - Final Exam Project Documentation

## 1. Executive Summary
NETIZEN is a modern ASP.NET Core Razor Pages application designed for the Final Exam of the Web Programming course. It demonstrates a complete end-to-end implementation of a user management system with role-based access control, secure authentication, and a premium administrative interface.

## 2. Technical Stack
- **Framework**: .NET 9.0 Razor Pages
- **Database**: MySQL with Entity Framework Core
- **Authentication**: Cookie-based Authentication with Role Claims
- **Frontend**: Bootstrap 5, Bootstrap Icons, Custom CSS3 Animations

## 3. Core Modules & Code Logic

### A. Authentication & Registration (`Auth.cshtml` / `Auth.cshtml.cs`)
- **Logic**: The system uses `Claims-Based Authentication`. When a user logs in, the server validates their email and password against the database. If successful, it creates a `ClaimsIdentity` containing the user's name and role.
- **Roles**: Supported roles are **Admin**, **User**, and **Student**.
- **UX Features**: Custom JavaScript handles the "Show/Hide Password" toggle for a better user experience.

### B. Admin Dashboard (`Dashboard.cshtml` / `Dashboard.cshtml.cs`)
- **Restriction**: Uses the `[Authorize(Roles = "Admin")]` attribute to ensure only administrators can access this page.
- **Statistics**: Automatically calculates counts for Admins and Students upon page load.
- **User Management**: Implements a responsive table with logic to handle missing roles by defaulting to "Student".

### C. User Management (`EditUser.cshtml` / `EditUser.cshtml.cs`)
- **Update Logic**: Allows administrators to modify user details. It uses `BindProperty` to map form data directly to the user model and saves changes securely using EF Core.

## 4. Design & Aesthetics
